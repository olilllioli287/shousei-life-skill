# AGENTS.md

This repository holds multi-agent working rules. When coordinating or dispatching work among several agents:

1. Read `skills-en/multi-agent-project/SKILL.md` (Traditional Chinese: `skills/multi-agent-project/SKILL.md`) first. Follow its pointers into `references/` and `templates/` only when the situation calls for them.
2. For study or course-reading work, use `skills-en/multi-agent-learning/SKILL.md` (experimental).
3. Before starting medium-or-larger work: agree on the completion criteria, write a spec from `templates/spec.md`, and get it reviewed before opening a branch.
4. When asking another agent to review, paste `templates/review-header.md` at the start of the prompt and give only the diff and spec, never your own conclusion.

這個倉庫放多 agent 協作的工作規範。要協調或派工給多個 agent 時，先讀 `skills/multi-agent-project/SKILL.md`，其餘檔案依情況再讀。
